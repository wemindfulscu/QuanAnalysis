# 量化决策系统 v2.1 - Web版

> 🌐 现已升级为现代化Web应用！跨平台、高性能、易扩展。

一个基于Web的量化分析决策系统，支持行业/概念板块、中证指数和恒生科技等多种指数类型，提供丰富的技术指标、交互式图表可视化和信号检测功能。

**📢 本项目已从桌面GUI版本升级为Web版本！**

## 🚀 快速开始

### 1. 安装依赖

```powershell
# Windows
pip install -r requirements.txt

# Linux/Mac
pip3 install -r requirements.txt
```

### 2. 启动Web服务

```powershell
# Windows - 使用启动脚本（推荐）
start_web.bat

# 或直接运行
python web_app.py
```

```bash
# Linux/Mac - 使用启动脚本（推荐）
chmod +x start_web.sh
./start_web.sh

# 或直接运行
python3 web_app.py
```

### 3. 访问系统

在浏览器中打开：
```
http://localhost:5000
```

## 核心功能

### 📊 综合图表可视化
- **一体化显示**：K线图 + 成交量 + RSI + MACD + KDJ 五合一
- **交互式缩放**：使用工具栏放大/缩小，所有子图联动同步
- **均线叠加**：支持 MA5、MA20、MA60 多条均线
- **信号标注**：买入（红色↑）、卖出（绿色↓）信号直接标注在K线上
- **中文优化**：自动选择系统最佳中文字体，清晰显示

### 🎯 常用操作
- **添加监控**：工具栏 → 添加监控（支持BK板块、93中证、恒生科技）
- **更新数据**：工具栏 → 更新数据（自动增量更新）
- **查看图表**：双击监控列表项，显示综合分析图
- **放大查看**：点击工具栏放大镜，框选区域放大
- **平移浏览**：点击工具栏十字箭头，拖动查看
- **扫描信号**：工具栏 → 扫描信号（检测所有指数）

### 📈 支持的指数类型
- **行业/概念板块**（代码以 BK 开头）
- **中证指数**（代码以 93 开头）
- **恒生科技**等港股指数

### 💡 技术指标
- **趋势指标**：MA5、MA20、MA60 移动平均线
- **强弱指标**：RSI14（相对强弱指标）
- **趋势动量**：MACD、Signal、Histogram
- **随机指标**：KDJ（K、D、J三线）
- **波动率**：ATR、布林带
- **成交量**：OBV、成交量柱状图

## 图表交互说明

### 工具栏按钮
- 🏠 **Home**：恢复原始视图
- ← **Back**：返回上一视图
- → **Forward**：前进到下一视图
- ➕ **Zoom**：框选区域放大
- ✋ **Pan**：平移浏览
- ⚙️ **Configure**：配置子图
- 💾 **Save**：保存图片

### 快捷操作
- **鼠标滚轮**：在图表上滚动可缩放X轴
- **拖动**：在平移模式下拖动查看不同区域
- **双击**：快速恢复原始视图
